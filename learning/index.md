## The Learning Loop

```
PROJECT RUNS → REFLECTION CAPTURES LESSONS → LESSONS STORED
     ↑                                              |
     |                                              ↓
AGENTS READ LESSONS ← PATTERNS COMPILED ← LESSONS ACCUMULATE
     |                                              |
     ↓                                              ↓
BETTER OUTPUT            TEMPLATES & SKILLS UPDATED (periodic)
```

## Lesson Priority Hierarchy

1. **CORRECTION** — Client explicitly corrected something. Highest priority.
2. **FAILURE** — Something went wrong (QA failed, revision needed). High priority.
3. **SUCCESS** — Approach worked well, client approved without changes.
4. **INSIGHT** — Pattern discovered across multiple projects.
5. **PREFERENCE** — Client behavioral preference learned.

## Update Rules

- After every project completion, append lessons to relevant agent files
- After every revision cycle, document what was wrong and what was fixed
- After every 5th project, do a cross-project pattern analysis
- Lessons marked [GRADUATED] are promoted to skills/templates
