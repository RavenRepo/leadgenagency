<!-- 13 AGENTS -->
<h2>

 🤖  The 13 Agents

</h2>

| Agent | Gate | Role |
|-------|:----:|------|
| `brief-parser` | — | Transforms raw brief into structured JSON |
| `icp-researcher` | ✅ | Builds deep ICP: demographics, psychographics, VOC |
| `lead-magnet-strategist` | ✅ | Selects format + crafts title |
| `lead-magnet-builder` | ✅ | Writes complete lead magnet content |
| `landing-page-copywriter` | ✅ | Crafts 60%+ CVR landing page |
| `funnel-architect` | — | Designs 5-stage funnel + tech stack |
| `email-sequence-writer` | ✅ | Writes 7-email nurture sequence |
| `content-strategist` | — | Builds 30-day content calendar |
| `post-writer` | — | Writes individual social posts |
| `newsletter-strategist` | — | Structures ongoing newsletter |
| `dm-copywriter` | — | Writes warm outreach scripts |
| `qa-checker` | ✅ | Full quality audit before delivery |
| `orchestrator` | — | Coordinates everything |

> ✅ = Human gate checkpoint

<!-- 7-DAY PIPELINE -->
<h2>

 📅  The 7-Day Pipeline

</h2>

```
 Day 1 ─────────────────────────────────────────────────────────────
 │
 └─▶ brief-parser ── [GATE 1: Missing info check]

 Day 2 ─────────────────────────────────────────────────────────────
 │
 ├─▶ icp-researcher ── [GATE 2: ICP Approval ✅]
 │
 └─▶ lead-magnet-strategist ── [GATE 3: Format + Title ✅]

 Day 3 ─────────────────────────────────────────────────────────────
 │
 ├─▶ lead-magnet-builder ── [GATE 4: Content Review ✅]
 │
 └─▶ landing-page-copywriter ── [GATE 5: Copy Review ✅]

 Day 4 ─────────────────────────────────────────────────────────────
 │
 ├─▶ funnel-architect ── (no gate — architecture only)
 │
 └─▶ email-sequence-writer ── [GATE 6: Sequence Review ✅]

 Day 5 ─────────────────────────────────────────────────────────────
 │
 ├─▶ content-strategist ── (no gate — plan stage)
 │
 └─▶ post-writer ── (first 14 days, no gate)

 Day 6 ─────────────────────────────────────────────────────────────
 │
 ├─▶ newsletter-strategist
 │
 └─▶ dm-copywriter

 Day 7 ─────────────────────────────────────────────────────────────
 │
 └─▶ qa-checker ── [GATE 7: Final QA ✅] ──▶ DELIVERY
```

<!-- HUMAN GATES -->
<h2>

 ⛩  Human Gates

</h2>

Every gate pauses for human review. You control quality at every step.

| Gate | Stage | Pause Point |
|:----:|-------|-------------|
| 1 | Brief Parser | Missing fields flagged |
| 2 | ICP Researcher | Demographics + VOC confirmed |
| 3 | Lead Magnet Strategist | Format + title approved |
| 4 | Lead Magnet Builder | Content reviewed |
| 5 | Landing Page Copywriter | Copy approved |
| 6 | Email Sequence Writer | Sequence reviewed |
| 7 | QA Checker | Final delivery decision |
